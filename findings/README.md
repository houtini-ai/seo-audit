# Phase 4 — Findings & gap list

Synthesis of Phases 1–3. This is where decisions get made.

## Files to produce
- `security.md` — concrete security issues, ranked by severity.
- `transportability.md` — what blocks clean cross-machine deployment.
- `data-quality.md` — every place crawl/GSC data is currently wrong or untrustworthy.
- `missing-checks.md` — Phase 1 checklist items that nothing in the current stack performs.

Each finding has: **symptom**, **root cause**, **evidence (file:line or test output)**, **severity**, **fix sketch**.
